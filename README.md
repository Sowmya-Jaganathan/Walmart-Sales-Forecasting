# Walmart Sales Forecasting and Inventory Optimization

This project focuses on analyzing sales, inventory levels, seasonal trends, and customer behavior to optimize supermarket operations.

## 📌 Objectives
- Forecast sales accurately
- Improve inventory turnover
- Understand customer segmentation
- Optimize supplier contributions

## 🛠 Tools Used
- **Excel**: Data Cleaning & Pivot Analysis
- **MySQL**: Data Extraction and Transformation
- **Power BI**: Visualization Dashboard

## 📊 Key Insights
- Premium customers lead in revenue
- Groceries are the highest selling category
- Inventory buffers need fine-tuning
- Supplier performance is uneven
- Seasonality heavily affects demand

## 📂 Files
- Cleaned dataset
- SQL queries
- Power BI Dashboard (PBIX)
- Project report and presentation
